# Lab: Reviewing Sign-In Logs in Microsoft Entra ID

## Objective

To review sign-in activity in Microsoft Entra ID and understand how login events can be used for troubleshooting.

---

## Scenario

User sign-in events were reviewed to confirm successful logins and identify how authentication details appear in the logs.

---

## Test Steps

- Opened Microsoft Entra ID Admin Center  
- Navigated to Sign-in logs  
- Filtered logs for a test user  
- Opened individual sign-in entries  
- Reviewed login status, application, location, and authentication details  
- Verified how MFA activity appeared in the sign-in record  

---

## What This Demonstrates

- How to locate user sign-in activity  
- How to confirm whether a login was successful, interrupted, or failed  
- How authentication steps appear in the log details  
- How sign-in logs support troubleshooting in Microsoft 365 environments  

---

## Outcome

The sign-in logs showed:

- User login activity for the selected account  
- Status of each login attempt  
- Application used during login  
- IP address and location details  
- Authentication steps, including MFA where applicable  

This made it possible to confirm login behavior and review the details of the authentication process.
