# Lab Plan: Microsoft 365 Trial Environment Setup

## Objective

To prepare a structured Microsoft 365 test environment for identity and access troubleshooting labs.

---

## Planned Setup Steps

1. Activate Microsoft 365 trial subscription.
2. Access Microsoft 365 Admin Center.
3. Access Microsoft Entra ID Admin Center.
4. Create multiple test users:
   - test.user1
   - test.user2
   - test.admin
5. Assign Microsoft 365 licenses to test users.
6. Confirm login access for each test user.

---

## Purpose of Multiple Test Users

Allows simulation of:

- Login failures
- License-related access issues
- MFA enforcement scenarios
- Account disable and recovery scenarios

---

## Expected Outcome

Fully functional Microsoft 365 test environment ready for troubleshooting labs.

---

## Importance

This environment will simulate real enterprise identity and access management conditions.
