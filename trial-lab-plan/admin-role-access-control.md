# Lab: Admin Role Assignment and Access Control

## Objective

To observe how assigning and removing admin roles affects user access in Microsoft 365.

---

## Scenario

A standard user is given administrative privileges and later has them removed.

---

## Test Steps

- Opened user profile for John Smith in the Admin Center  
- Assigned Global Administrator role  
- Logged in as the user and accessed the admin portal  
- Removed the Global Administrator role  
- Logged in again to verify access restrictions  

---

## What This Demonstrates

- Difference between standard user and admin access  
- How roles control permissions in Microsoft 365  
- Importance of limiting admin privileges  
- Basic role-based access control (RBAC)  

---

## Outcome

After assigning Global Administrator:
- User was able to access the Microsoft 365 Admin Center  
- Full administrative access was available  

After removing the role:
- User was no longer able to access admin features  
- Access to the admin portal was denied  

---

---

## Notes

This scenario shows how user roles directly affect access levels in Microsoft 365. It highlights the importance of assigning admin privileges only when required.
