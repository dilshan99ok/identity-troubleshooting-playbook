# Common Account States in Microsoft 365

Understanding account states helps explain why a user may experience login or access issues.

## Active Account

- User can sign in
- Access depends on license and permissions

## Sign-in Blocked

- User cannot log in
- Error usually indicates account is disabled

## Password Expired

- User must reset password before access
- Login attempt fails until updated

## MFA Not Registered

- User may get stuck in MFA setup loop
- Common when device or phone changes

## No License Assigned

- User can log in
- Services like Teams or Exchange may not work

## Deleted Account

- User cannot sign in
- Account may still be recoverable within retention period
